## Future Market – 로봇 픽업 마트 시뮬레이터

미래의 마트에서는 주문이 들어오면 로봇이 주문서에 적힌 상품을 전부 가져와
패킹한 뒤 입구까지 가져다주는 모습을 상상할 수 있습니다.

이 프로젝트는 그 흐름을 **UI 시뮬레이션**으로 표현한 작은 플레이그라운드입니다.

---

## 사용 방법 / 주요 기능

1. **상품 진열**
   - 주문을 받기 위해서는 먼저 진열대(12 × 4 그리드) 박스를 클릭해  
     상품을 **최소 1개 이상** 진열해야 합니다.
   - 이미 진열된 상품은 다른 칸에 중복 진열할 수 없습니다.
   - 맨 오른쪽 하단 칸은 진열이 불가능한 `입구` 영역입니다.

2. **주문 시작**
   - 상품이 한 개 이상 진열되어 있으면,
     우측 상단의 **`주문 시작` 버튼**을 눌러 주문 시뮬레이션을 시작할 수 있습니다.
   - 진열된 상품이 하나도 없으면 주문을 시작할 수 없습니다.

3. **주문 생성 규칙**
   - `주문 시작` 버튼을 **처음 클릭하는 순간**,  
     대기 시간 없이 **즉시 첫 주문 1개가 랜덤으로 생성**됩니다.
   - 이후에는 약 **15초마다 새 주문이 랜덤하게 생성**됩니다.
   - 주문에 포함되는 상품들은 **진열대에 실제로 올려둔 상품만** 대상이며,  
     재고 수량을 고려해 랜덤하게 선택됩니다.

4. **로봇 이동 및 픽업**
   - 주문이 들어오면 로봇은:
     - 이번 주문에 필요한 상품이 진열된 칸들만 골라 방문하고
     - 방문 순서를 전부 순열(permutations)로 계산해서
     - **총 이동 칸 수가 최소가 되는 경로**로 이동합니다.
   - 각 상품 칸과 입구에서는 잠시 멈추며, 픽업/도착 이펙트가 재생됩니다.

5. **주문 완료 흐름**
   - 로봇이 모든 상품을 픽업한 뒤 **입구 칸으로 돌아오면**  
     해당 주문은 **완료된 상태**로 변경됩니다.
   - 로봇은 자동으로 **다음 대기 중인 주문을 이어서 처리**합니다.

좌측 사이드바에서는 대기 중/완료된 주문 목록을,
우측 사이드바에서는 상품별 남은 재고 수량을 확인할 수 있습니다.

---

## 기술 스택

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **UI**: React, Tailwind CSS

---

## 실행 방법

프로젝트 루트에서 의존성을 설치한 뒤 개발 서버를 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)에 접속하면
미래 마트 로봇 픽업 시뮬레이션 화면을 볼 수 있습니다.
